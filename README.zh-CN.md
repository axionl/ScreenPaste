# ScreenPaste

轻巧的 Windows 截图与标注工具：一键截图、即时标注、钉选到屏幕。

## 功能

### 截取
- 整个画面（支持多屏幕）
- **窗口与 UI 元素自动识别**：鼠标移到窗口或界面元素（按钮、面板、网页区块）上自动描出范围，点一下即截取；**滚轮**可切换检测层级（元素 ⇄ 窗口）
- 拖拽框选自定义范围，附尺寸标示；**像素放大镜**全程跟随光标（框选与编辑模式皆显示），提供十字定位、坐标与像素颜色，`C` 复制色值、`Shift` 切换 16/10 进制
- **框选后可再调整**：拖拽四角与边中点的控制点改变范围；未选工具时拖拽选区内部可整体移动，已画的标注会固定在画面内容上

### 标注
截取后在鼠标旁弹出**图标工具栏**（可拖拽移动、自动避开屏幕边缘）：

- **记号笔** — 实心笔触，可调粗细 / 颜色 / 不透明度
- **荧光笔** — 半透明叠色，可调粗细 / 颜色 / 不透明度
- **文字** — 可选字体 / 大小 / 颜色 / 样式（正常、粗体、斜体、删除线）；点击框外即完成输入
- **形状** — 方形 / 圆角方形 / 圆形，外框或填充，可调线条粗细与颜色
- **直线 / 箭头** — 拖拽画线，两端可各自切换是否为箭头，可调粗细与颜色；按住 `Shift` 吸附 45° 角
- **贴图** — 贴上 PNG / JPEG / WebP 图片，可拖拽移动、滚轮缩放
- **模糊** — 高斯模糊 / 马赛克，可调模糊程度；盖在所有标注之上，能遮住其下的笔画与形状，并可直接拖拽移动（移动后重新采样新位置的画面）
- **局部放大** — 拖拽框出要放大的区域，旁边自动放出放大检视：方形 / 圆角 / 圆形，可调倍率（1.2–10×）、边框粗细与颜色、连接线、阴影、平滑（关闭即显示硬边像素格），以及放大内容是否含其他标注；放大检视与**来源外框都可以随时拖拽移动** — 移动来源外框即改变放大的内容，连接线随之重新指向；选取放大镜后，来源外框会出现**八个控制点可调整大小**（放大检视依倍率同步缩放），滚轮则可改倍率
- **直接选取 / 移动** — 鼠标移到任何已画的标注上即可**直接拖拽移动**，`Delete` 删除；移动与删除皆可撤销
- **颜色选择器** — 支持 Hex 输入、RGB 与不透明度调整（半透明以棋盘格预览）；自定义颜色会跨次记住，右键色票即可移除
- **撤销 / 重做** — 按钮与快捷键皆可，所有滑杆附即时数值显示

### 输出
- 复制到剪贴板
- 保存为 PNG / JPG（另存或快速存到默认文件夹）
- **钉选到屏幕**：图像浮于最上层，可拖拽、滚轮缩放、右键菜单；钉多张时 Esc 先关闭聚焦的那张、无聚焦则全关

### 区域录制
- 专属全局快捷键（默认 **F2**）启动：拖拽框选要录制的范围，或**点击窗口自动识别**（滚轮切换窗口／元素层级，与截图相同），再按一次快捷键（或点停止按钮）结束
- 录制时以红框标示范围，旁边小工具栏显示计时与停止按钮
- 结束后打开**编辑器**：循环预览、拖拽时间轴控制点**修剪头尾**（`Space` 播放、`←→` 逐帧、`I`/`O` 设起讫点），导出时显示进度
- **录制中可拖拽红框边框移动录制范围**，框内维持可正常操作被录的窗口
- 编辑器具备与截图相同的**标注能力**（文字 / 形状 / 直线箭头 / 贴图 / 高斯模糊 / 马赛克，含完整选项列，标注可直接拖拽移动、`Delete` 删除）；`Ctrl+C` 快速导出并将文件放上剪贴板
- 导出格式 **GIF / MP4 / WebP** 于编辑器直接切换；也可于设置改为「录完直接保存」跳过编辑器
- 可录制鼠标指针、可设置帧率（10–30 fps）
- **收音**：系统声音（loopback）／麦克风／两者混音，可于设置选择；声音仅存于 **MP4**（GIF、WebP 无声）。若无可用音频设备（远程桌面常见）会自动降级为无声录制
- 由随附的 `ffmpeg` 进行编码，无需另外安装

### 其他
- 全局快捷键（截图默认 **F1**、区域录制默认 **F2**）与**系统托盘**图标启动
- **多国语言**：繁體中文 / 简体中文 / English / 日本語 / 한국어 / Français / Deutsch / Español（默认跟随系统）
- **浅色 / 深色 / 跟随系统**主题
- 集中式**设置窗口**：语言、快捷键、主题、开机启动、保存文件夹（快捷键字段可直接按组合键设置）
- 可设置**开机自动启动**
- **自动更新**：通过 GitHub Releases 检查新版（可于设置开关、或手动立即检查），有更新时询问并一键下载安装

## 安装

到 [Releases](https://github.com/taida957789/ScreenPaste/releases) 下载：

- **`ScreenPaste-<版本>-setup.exe`** — 安装版（免系统管理员权限，安装于 `%APPDATA%\ScreenPaste`，含开始菜单快捷方式与卸载程序）
- **`ScreenPaste-<版本>-win-x64-portable.zip`** — 免安装绿色版

两者皆为自包含，**无需另外安装 .NET Runtime**，并已随附 `ffmpeg`（供区域录制使用）。

## 快速使用

![工具栏](screenshots/ui.png)

1. 启动后常驻系统托盘，按 **F1**（或左键单击系统托盘图标）开始截图。
2. 鼠标移到窗口自动描框、点击截取，或拖拽框选自定义范围。
3. 在弹出的工具栏选工具、调整参数，于选区上标注。
4. 按 **复制 / 保存 / 钉选** 输出；`Esc` 离开截图（会先询问，可勾选不再提醒）。

录制：按 **F2** 拖拽框选范围即开始录制，再按一次 **F2**（或点停止按钮）结束；接着在编辑器中预览、修剪头尾并选择 GIF/MP4/WebP 导出（设置中可改为录完直接保存）。

## 快捷键一览

| 情境 | 按键 | 功能 |
|---|---|---|
| 全局 | `F1` | 开始截图（可自定义） |
| 全局 | `F2` | 区域录制 开始 / 停止（可自定义） |
| 框选中 | 滚轮 | 切换检测层级（UI 元素 ⇄ 窗口） |
| 框选 / 标注中 | `C` | 复制放大镜指向的像素色值 |
| 框选 / 标注中 | `Shift` | 色值显示切换 16 / 10 进制 |
| 标注中 | `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（可自定义） |
| 标注中 | `Ctrl+C` | 复制到剪贴板（可自定义） |
| 标注中 | `Ctrl+S` / `Ctrl+Shift+S` | 另存 / 快速保存（可自定义） |
| 标注中 | `Delete` | 删除选取的标注 |
| 标注中 | `Shift`＋拖拽（直线） | 吸附 45° 角 |
| 标注中 | `Enter` 或点击框外 | 完成文字输入（`Shift+Enter` 换行） |
| 标注中 | `Esc` | 取消选取 → 离开截图（先询问，可设置关闭） |
| 录制编辑器 | `Space` | 播放 / 暂停 |
| 录制编辑器 | `←` / `→` | 逐帧前进 / 后退 |
| 录制编辑器 | `Home` / `End` | 跳至修剪起点 / 终点 |
| 录制编辑器 | `I` / `O` | 于播放位置设置修剪起点 / 终点 |
| 录制编辑器 | `Ctrl+C` | 快速导出并将文件复制到剪贴板 |
| 钉选窗口 | `Ctrl+C` / `Esc` | 复制 / 关闭 |

设置（快捷键、工具默认值、主题、开机启动、录制格式/帧率等）皆可于系统托盘菜单 →「设置…」的窗口中调整。

> 从源码构建时，先执行 `scripts/fetch-ffmpeg.ps1` 下载随附的 `ffmpeg.exe`（CI 于发布时会自动执行）。
